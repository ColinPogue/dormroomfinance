# Automatic publishing — restored November 12, 2026

User explicitly requires fully automatic operation with no article reviews. The existing loaded local LaunchAgent runs Tuesday, Thursday, Saturday at 9 AM local time. The Mac and user session must remain available, as with the original setup. No new cloud credentials or services were configured.

main.py now chooses a topic, researches it through Claude web search restricted to primary-source domains (with direct official-page retrieval as a fallback), writes the article, runs a separate automated checking pass, validates structure and source links, fetches an optional Pexels cover, then commits the article and cover atomically. GitHub Pages runs build/browser checks and deploys automatically. There is no review queue or human approval gate. Normal API usage includes the bounded web searches and checking pass, using the existing Claude account.

A daily guard and process lock prevent duplicate/overlapping runs. The exact pending article is saved before publication and reused after ambiguous failures. Existing URLs are never overwritten by automation. Exhausted topic queues are expanded automatically rather than cycling through old articles. Failed research or checks can try another topic, with a bounded three-attempt limit; provider failures can still prevent a scheduled post. Sources and automated checks reduce errors but are not a guarantee of accuracy.

All new automated articles carry automated:true and a visible AI/publishing disclosure. sourceChecked records the automatic research date; it does not imply human review. reviewed remains reserved for the 21 earlier sourced refreshes. Legacy archive labels remain accurate. Human review is not required for new articles or topic expansion.

Use `python automation/main.py --dry-run` only for validation: it generates and checks an article into exports/automatic-validation without public writes, counters, or notifications. Regular invocation respects the original last_run.json state. The original publisher.py is preserved; the new auto_publisher.py provides atomic no-overwrite commits.

Validation limitation: live dry-run generation in this restricted Codex process could not reach the Claude API. No article was generated or published during that test. Automated mocked pipeline tests and the production website build validate the implementation; the next scheduled run uses the existing Mac process outside this session. Search feature/account availability is not claimed to have been live-tested; direct primary-source retrieval is attempted if search is unavailable.
